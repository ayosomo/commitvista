# Security policy

## Supported versions

CommitVista is a portfolio prototype. Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use the repository's **Security → Report a vulnerability** form so the report can be assessed privately. Include the affected area, reproduction steps, likely impact and any suggested mitigation. Please avoid accessing data that is not your own while investigating.

You can expect an initial acknowledgement within five working days. Confirmed issues will be prioritised according to their impact and addressed through a reviewed change.

## Scope

CommitVista reads public GitHub REST API data in the browser. Phase 1 does not collect passwords, persist access tokens or provide a production authentication system. Never submit real credentials, private repository data or customer information to the demo.
